# Ревью Resonance — 5 сентября 2026

Проведён целевой обзор авторизации, API-ошибок, загрузки вложений, маршрутизации и загрузки фронтенда; выполнен полный существующий набор тестов. Интерфейс проверен в локальном Docker-стеке на обычном и узком экране (390 × 844). Это не исчерпывающий аудит безопасности всех интеграций.

## Исправленные проблемы

| Приоритет | Проблема | Изменение |
| --- | --- | --- |
| P1 | Фильтр вложений разрешал HTML через `text/*`; MIME с параметрами обходил запрет SVG. Файлы доступны на origin приложения. | Запрет HTML/XHTML/SVG по расширению и нормализованному MIME. Новые S3-объекты выдаются с `Content-Disposition: attachment`, включая загрузки с недостоверным MIME. |
| P2 | Синхронный S3 upload блокировал event loop API. | Вызов перенесён в thread pool. |
| P2 | Ошибка `/auth/me` после выдачи токена поглощалась: форма считала вход успешным. | Ошибка возвращается форме входа и вызывающим обновление профиля. |
| P2 | Выход очищал localStorage других приложений на том же origin. | Очистка ограничена ключами Resonance с сохранением предпочтений оформления. |
| P2 | Сообщение конфликта состава релиза терялось внутри `detail.message`. | API-адаптер показывает содержательное сообщение вместо `Conflict`. |
| P2 | Все страницы, графики и Kanban загружались уже на экране входа. | Защищённые страницы загружаются через `lazy`; Suspense сохраняет оболочку приложения. Начальный JS: 1967,11 → 709,31 кБ (примерно −64%). Это размер сборки, а не измерение времени загрузки. |
| P3 | Поля авторизации/регистрации не были связаны с подписями; кнопка показа пароля не имела имени. | Доступные подписи, состояние переключателя, видимый клавиатурный фокус и увеличенная область кнопки. |
| P3 | Заголовок раздела релизов показывал Resonance; мобильная высота использовала статический viewport. | Добавлены заголовок/переход назад, динамическая высота, отступы и выравнивание форм. |

## Проверки

- Backend: 155 тестов прошли, включая API-проверку авторизации загрузки, отказ HTML, успешную загрузку и тест метаданных S3.
- Frontend: 69 тестов прошли; typecheck, lint и production build завершились успешно.
- `git diff --check`: без ошибок.
- Собраны Docker-образы backend/frontend; обновлены только эти два контейнера через существующий local compose и его `.env.example`. Оба контейнера healthy. База, MinIO и тома не пересоздавались.
- В браузере проверены вход, регистрация, главная, вопросы, мобильное меню, список и карточка релиза. После обновления подтверждены новые подписи полей и заголовок релизов.

## Ограничения и дальнейшие работы

- Сохранились 40 прежних предупреждений ESLint (Fast Refresh и зависимости React hooks), предупреждения backend о deprecated API и предупреждение размера начального JS-файла. Массовая перестройка модулей ради удаления предупреждений не выполнялась.
- Новая S3-метаинформация не меняет ранее сохранённые объекты. Для старых вложений нужна отдельная инвентаризация и изменение метаданных либо защита файлового маршрута на gateway.
- Реальные вызовы Jira/TestOps/Kanban, Matrix/Telegram и загрузка пользовательских файлов в MinIO не выполнялись. Тесты хранилища используют mock; backend-тесты работают с SQLite, а не с копией рабочей PostgreSQL.
- Сохранены существовавшие до ревью изменения `queries.ts`, `ReleasesPage.tsx`, `ReleaseDetailPage.tsx` и две записи в `AGENTS.md`; они не выдаются за результат этого ревью. Docker-сборка включает текущую рабочую копию целиком.
